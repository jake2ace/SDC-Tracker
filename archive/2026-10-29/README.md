# Local project archive — 2026-10-29

This folder backs up ordinary source code, competition resources, presentation materials, validation evidence, and historical project files from the local hackathon workspace. The current source and its existing history remain in this repository.

Personal CVs, local credentials, runtime databases, signed forms, and selected account/billing screenshots are excluded. Dependencies and regenerable build output are also excluded.

Download all `.tar.gz` files and `SHA256SUMS` from this folder. Verify them with `shasum -a 256 -c SHA256SUMS`, then extract each archive into the same empty folder. The archives preserve relative paths; the included manifest records SHA-256 hashes of retained files. A historical Git bundle is included for recovery of the earlier project history.

This is a file archive and does not alter the application runtime.
