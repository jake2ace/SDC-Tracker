## 自动验收

在仓库运行 `npm test`，11 个测试全部通过：

- 未登录、CSRF（含非 ASCII token）、跨来源请求与退出会话。
- 只读权限和伪造身份／角色请求头无效。
- 草稿、待审批、被驳回状态不能执行，也不会产生结果。
- 批准后可以执行一次；重复执行被拦截且不会增加执行次数。
- 模拟接口失败返回 503、记录 request ID 和失败日志；保留批准状态以便重试，不影响其他操作。
- 工作区之间的对象及成功日志隔离。
- 输入错误与被拒绝操作可在当前工作区查询，不生成业务记录。
- 关闭服务并重新打开同一个 SQLite 文件后，操作、日志和有效会话仍保留。
- 关闭演示模式后，演示账号入口与登录不可用。
- 畸形请求 URL 返回 400，之后健康检查仍正常。
- 超过 8 KB 的 JSON 请求返回 413、记录错误日志，服务继续可用。

测试代码在 [test/foundation.test.js](../test/foundation.test.js)。每个场景使用独立临时数据库，不修改正常演示数据。
