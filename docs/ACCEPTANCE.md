# 初赛完成标准

自动开票、AI 催收、30 天现金流预测都是初赛范围。下列复选框仅在实际验收通过后勾选。

## 自动开票

- [ ] 完成里程碑后，生成客户、金额、币种、付款节点正确的草稿。
- [ ] 未批准、被驳回或无权限时不能执行开票。
- [ ] 模拟会计接口成功返回编号后才显示成功；失败可见。
- [ ] 同一节点的重复点击、事件和重试不生成第二张发票。
- [ ] 到期日按付款约定的起算点计算，不把草稿日期误当实际开票日期。

## AI 催收

- [ ] 识别未付的逾期发票，按正确金额、逾期天数和历史记录生成提醒。
- [ ] 文案可修改，人工批准后才模拟发送，并保存记录。
- [ ] 已付款停止催收，同一次提醒不重复发送。
- [ ] AI 调用失败有可见提示及可人工编辑的模板，不谎报生成或发送成功。

## 现金流预测

- [ ] 根据初始余额、预计收款和计划支出，计算未来 30 天每日余额。
- [ ] 支持按时到账与延迟到账两种情景，标出低于安全线的日期和金额。
- [ ] 可从图表结果追溯到收支明细，金额能够手工复核。
- [ ] 日期、状态或计划支出变化后重新计算；已实际收到的款项不再重复算作预计收款。

## 整体与交付

- [ ] 一组公司数据贯穿三个功能，完整流程可以现场操作。
- [ ] 后端执行角色和公司范围限制；操作有日志，刷新后保留状态。
- [ ] 换另一家公司的合成数据后，无需改业务代码即可演示。
- [ ] 多案例验证通过：正常到账、延迟 7/14 天、窗口外到账、已收款及滚动预测；每例记录预期与实际结果，不能只跑通一个故事。现金流案例见[验收表](FORECAST.md#多案例演示与验收)。
- [ ] 部署版本可访问，按 README 能在干净环境复现；检查部署重启后的数据行为。
- [ ] 记录人工步骤、任务耗时等可测收益；区分模拟结果和目标，说明 SDG 8 联系。
- [ ] PRD、PPTX、工具声明、演示视频、公开仓库与链接全部核对完成。

## 验收证据怎么留

在对应 Issue 中写：测试输入、操作步骤、预期结果、实际结果，以及截图或短视频。发现问题另开 Issue，未通过的功能保持在“进行中”或“待验收”，不标记完成。
